# 📊 Smart Data Analyzer

🚀 A powerful **Streamlit-based Data Analytics Dashboard** that combines **statistics, probability, and vector similarity** with a modern Power BI-style UI.

---

## 🎯 Project Overview

The **Smart Data Analyzer** allows users to:

* Upload real-world datasets 📂
* Perform statistical analysis 📊
* Calculate probability insights 🎲
* Compare data using vector similarity 🔢
* Visualize trends with interactive charts 📈
* Generate intelligent insights 🤖

---

## 🧠 Features

### 📁 Data Upload

* Upload any CSV dataset
* Automatic detection of numeric columns

### 📊 Statistical Summary

* Mean, median, min, max
* Full dataset description

### 🎲 Probability Analysis

* Select column and range
* Calculate probability dynamically

### 🔢 Vector Similarity

* Dot Product
* Cosine Similarity
* Compare any two rows

### 📈 Interactive Visualizations

* Histogram
* Box Plot
* Line Chart
* Scatter Plot

### 📊 Dashboard UI

* Power BI-style layout
* KPI metrics (Rows, Mean, Min, Max)
* Sidebar filters

### 🤖 AI Insights

* Data skewness detection
* Smart observations

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/smart-data-analyzer.git
cd smart-data-analyzer
```

### 2️⃣ Create virtual environment

```
python -m venv venv
venv\Scripts\activate   (Windows)
```

### 3️⃣ Install dependencies

```
pip install -r requirements.txt
```

### 4️⃣ Run the app

```
streamlit run app.py
```
